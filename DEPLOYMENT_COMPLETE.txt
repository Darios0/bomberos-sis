🚀 DESPLIEGUE EN CENTOS 9 (3 PASOS)

Paso 1: En tu máquina local
  $ git clone https://github.com/Darios0/bomberos-sis.git
  $ cd bomberos-sis

Paso 2: Envía al servidor CentOS 9
  $ scp -r . root@192.168.1.100:/tmp/bomberos-sis/
  $ ssh root@192.168.1.100

Paso 3: En el servidor CentOS ejecuta
  $ cd /tmp/bomberos-sis
  $ bash docker-deploy.sh

¡LISTO! El script hace TODO automáticamente:
  ✓ Instala Docker + Docker Compose
  ✓ Genera contraseñas seguras
  ✓ Configura usuario 'bomberos'
  ✓ Ejecuta migraciones de BD
  ✓ Configura firewall
  ✓ Setup auto-restart en boot

Accede a: http://<server-ip>

⚡ COMANDOS ÚTILES

Monitoreo:
  docker compose ps                         # Estado de servicios
  docker compose logs -f                    # Logs tiempo real
  docker stats                              # Uso de recursos

Operaciones:
  docker compose restart                    # Reiniciar todo
  docker compose down                       # Detener servicios
  docker compose up -d                      # Iniciar servicios

Database:
  docker compose exec postgres psql -U bomberos bomberos_db

Backup:
  docker compose exec -T postgres pg_dump -U bomberos bomberos_db > backup.sql

Actualizar:
  sudo bash /opt/bomberos-sis/update.sh     # Con zero-downtime
